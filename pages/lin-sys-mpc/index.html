Model Predictive Control for Linear Systems

Combine sampled-data feedback, controller synthesis, and reachable-set verification in a linear optimization problem. AROC optimizes correction inputs and drives the system into a terminal region. The implementation supports MATLAB linear programming solvers, MOSEK, and Gurobi.
