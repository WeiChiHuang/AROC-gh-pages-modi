Motion Primitive Based Control

The motion primitive based control algorithms described automatically synthesize feasible and close-to-optimal controllers for single motion primitives offline. These motion primitives can be used to construct a maneuver automaton (see AROC manual Sec. 3), which is then applied for online control (see AROC manual Sec. 3.5).
