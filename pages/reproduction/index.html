Environment, scope, and validation notes

Environment: MATLAB R2024b, CORA v2026.0.1, YALMIP R20250626 and CasADi 3.7.2/IPOPT. The first six controller examples started with SeDuMi available while the initial MOSEK license was expired. After renewal and a successful fresh-process solve, the terminal-region and remaining cases use independent AROC/CORA copies with MOSEK 11.0 available and upstream solver selections. Every row names its execution group; the manifest preserves group metadata. Concurrent runs and different solver environments make wall times unsuitable for performance comparisons.

Each example retains its original benchmark settings, including real-time options. “Example executed” means the script finished and the listed sampled checks passed. It is distinct from “Test passed”, which refers to the original MATLAB unit-test assertions. Sampling and script completion are not independent formal proofs. Failed items are listed without a success claim.

Plot-data downloads contain time-point set geometry and up to ten recorded simulations per results object; continuous-time tubes are omitted. Original full MATLAB workspaces remain locally in research/full-run, research/mosek-run and research/remaining-run according to the execution group. This display subset does not change which trajectories were checked.

Wall times include script execution, sampled checks, data serialization, and figure export; the first case also includes parallel-pool initialization. These numbers are not a controlled performance comparison between algorithms.

Coverage is by algorithm family and method variant; not every benchmark script in the repository is included. The upstream root-level test entry point selects 20 script-based sections; additional function-style component tests in nested directories are outside this record.
